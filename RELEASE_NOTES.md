# Northbound 0.2.0-alpha.4

Changes since `v0.2.0-alpha.3`.

- Update the pinned TrueNorth Core release to v30.5.5. Wallet integration tests now check the specific rejection reason for each malformed P2QRH witness.
- Show the history-based total balance on the wallet overview, refine scrolling and dialogs, and simplify settings and address handling.
- Check server compatibility before saving a wallet server URL.
- Build server release binaries and add NixOS deployment support.
